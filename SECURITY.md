# Security Policy

## Supported Versions

Only the latest release of Countersign is supported with security fixes. Please update before
reporting an issue you have not reproduced on the latest release.

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting: open the
[Security tab](https://github.com/Gord1y/countersign/security) on this repository and use "Report
a vulnerability". Do not open a public issue for a security report.

Please include:

- The Countersign version (`countersign --version`) and macOS version
- The host involved (Claude Code, Codex, Cursor or Antigravity) and its version
- Steps to reproduce, and what you expected instead
- Relevant lines from `~/Library/Logs/Countersign/countersign.log`, if any
- The impact you believe the issue has

## What happens next

You will get an acknowledgement of the report. Confirmed vulnerabilities are fixed in a patch
release; you are welcome to be credited in the release notes if you would like, and welcome to
stay anonymous otherwise.
